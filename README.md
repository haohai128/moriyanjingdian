# 末日眼镜店 · 第一副备用镜

一个 2D 末日探索与经营游戏的第一章 Demo。

**在线试玩：https://haohai128.github.io/moriyanjingdian/**

太阳不再可靠，人们只在夜间出行。你经营一家眼镜店，也在废弃街区搜集旧镜片和零件，为送货员修配一副备用镜。

## 操作

使用电脑键盘与鼠标。A / D 或左右方向键移动，E 互动，Tab 背包，Esc 暂停，鼠标操作维修台。开始后先向左走，与阿远交谈接单。

手机和平板支持横竖屏：按住屏幕左移 / 右移，靠近标记后点互动；可同时按住快走。屏幕上有背包和暂停按钮。维修台用手指点选、来回擦拭及点按旋紧。内容较长的菜单可以滑动查看。

本章包含店铺、街道、两层居民楼、搜集、人物支线、手动维修与订单交付，约 8–15 分钟。

## 部署

本仓库保存可直接运行的 Godot Web 发布文件。`index.html` 位于根目录，所有资源使用相对路径；游戏无需后端、外部字体或素材服务。

GitHub Pages 发布源：`main` 分支的 `/ (root)`。`.nojekyll` 用于直接发布静态文件。

`index.pck` 包含游戏场景、脚本、中文字体与音效逻辑，`index.wasm` 是引擎。应保留文件名及完整文件集。更新版本时替换网页发布文件后提交，Pages 会自动重新发布。

浏览器允许网站存储时自动保存当前进度；清除站点数据会清除存档。不同浏览器之间不会同步。

## 首次加载

页面打开后会提前下载并准备游戏，点击开始时复用已准备的资源。加载提示区分下载、准备和进入游戏；不会在点击时重复下载。

性能专项更新：资源准备完成后先在介绍页遮罩后启动到标题，再由点击进入。不会提前开始第一夜或写入新存档；游戏内容与画面保持一致。此改动缩短准备完成后的点击等待，不减少引擎下载量。若需回退原来的按需启动，可在地址后加 `?loader=legacy`。

当前引擎文件约 39.5 MB，GitHub Pages 的 gzip 响应实际传输约 10.25 MB；游戏内容包约 300 KB。首次加载速度受访问网络和设备初始化速度影响。浏览器可能复用缓存，但不能保证每次都命中。本机预览速度不能代表其他玩家的公网访问速度。
