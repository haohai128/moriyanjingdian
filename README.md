# 末日眼镜店 · 第一副备用镜

一个 2D 末日探索与经营游戏的第一章 Demo。

**在线试玩：https://haohai128.github.io/moriyanjingdian/**

太阳不再可靠，人们只在夜间出行。你经营一家眼镜店，也在废弃街区搜集旧镜片和零件，为送货员修配一副备用镜。

## 操作

使用电脑键盘与鼠标。A / D 或左右方向键移动，E 互动，Tab 背包，Esc 暂停，鼠标操作维修台。开始后先向左走，与阿远交谈接单。

本章包含店铺、街道、两层居民楼、搜集、人物支线、手动维修与订单交付，约 8–15 分钟。暂未提供手机触屏操作。

## 部署

本仓库保存可直接运行的 Godot Web 发布文件。`index.html` 位于根目录，所有资源使用相对路径；游戏无需后端、外部字体或素材服务。

GitHub Pages 发布源：`main` 分支的 `/ (root)`。`.nojekyll` 用于直接发布静态文件。

`index.pck` 包含游戏场景、脚本、中文字体与音效逻辑，`index.wasm` 是引擎。应保留文件名及完整文件集。更新版本时替换网页发布文件后提交，Pages 会自动重新发布。

浏览器允许网站存储时自动保存当前进度；清除站点数据会清除存档。不同浏览器之间不会同步。
